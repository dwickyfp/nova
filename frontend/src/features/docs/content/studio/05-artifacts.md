## What it is

**Artifacts** in Studio lists the native dashboards you can open. It is the same
list and the same editor as the [Dataviz](/docs/dataviz/what-is-dataviz) tab:
a dashboard opened here is the same document, with the same history, as in
Dataviz.

Every chart runs its query again with your current role when you open it, so
the numbers are current and show only the rows your role may read.

## Open a dashboard

1. In Studio's left rail, click **Artifacts**.
2. Use **Search dashboards** to narrow the list. Each card shows the workspace,
   whether you can edit it, when it last changed, and **Published** or
   **Draft**.
3. Click a dashboard to open it. Click the back arrow to return to the list.

To create one, click **New dashboard**. To build charts, filters and layouts,
see [Build a native dashboard](/docs/dataviz/native-dashboards).

## Limits

- Charts and dashboards saved by the earlier BI tool are no longer available.
  Rebuild them as native dashboards, or ask the Dataviz assistant to build one.
