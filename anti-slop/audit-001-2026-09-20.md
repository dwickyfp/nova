## Detail

### Finding 1 — R-02, em dash as empty-value placeholder (HIGH)

Five UI sites render `—` when a value is absent. The rule is absolute for text the
agent writes, and a placeholder is text. Replace with a word that reads correctly
in each context (for example "Not set", "None", or nothing at all).

### Finding 2 — R-27, no error state (HIGH)

Every data view implements loading and empty but not error. `useQuery` exposes
`isError`; nothing reads it. A failed request leaves the pane blank, which reads
as "no data" rather than "the request failed". This is the single largest gap and
it repeats across eight files.

### Finding 3 — R-27, chart with no zero-data explanation (HIGH)

The Overview chart always renders. With an empty series it draws a flat line at
zero, which looks like real data. It needs an empty state that says the agent has
no usage yet.

### Finding 9 — R-02, em dash in comments (HIGH)

Four JSDoc blocks use `—`. The rule's carve-out covers the antislop documentation
itself, not project comments.

## Not findings (checked, passed)

- **R-17 / R-38**: every number on Overview and Observability comes from the
  message store (`total_sessions`, `total_tokens`, `total_active_users`,
  per-turn tokens). No invented metrics, no deltas without a series.
- **R-18 / R-28**: no testimonials, no FAQ. Nothing fabricated.
- **R-24**: every sidebar entry and tab resolves to a real route.
- **R-26**: the "Open in Nova Studio" button opens a real URL; tabs switch real
  content; dialogs close on Escape (Radix default).
- **R-01**: palette comes from Nova's semantic tokens (`--primary`, `--muted`,
  `--border`). No default gradients or glows.
- **R-11**: radius uses a small set (`rounded-2xl` on cards, `rounded-full` on
  circular controls). Not uniform pills.
- **R-12**: shadow only on the composer and the fixed Verify bar, both of which
  lift above the page. Reason holds.
- **R-03**: layouts use `min-w-0`, `overflow-x-auto`, and collapse to one column
  under `sm`. No hardcoded heights.
- **R-37**: Nova has `DESIGN.md`; direction exists.
